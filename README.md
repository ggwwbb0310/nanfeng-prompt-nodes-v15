# nanfeng-prompt-nodes-v15

ComfyUI custom node package for NanFeng prompt, storyboard, audio-drive, and continuation workflows.

## Included
- NanFeng H3 prompt and generation nodes
- Storyboard and audio-drive APIs
- Continuation workflow helpers
- Web assets for the ComfyUI extension

## Installation
1. Copy this repository into `ComfyUI/custom_nodes/nanfeng-prompt-nodes-v15`.
2. Install the dependencies required by your NanFeng/ComfyUI environment.
3. Configure API settings through the node UI or a local `.env` file.
4. Restart ComfyUI.

## Configuration
Copy `.env.example` to `.env` and fill in your own values. Never commit API keys.
